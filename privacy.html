SonarrBot Privacy Statement

Scope

SonarrBot (aka Dory) is a self-hosted instance of YAGPDB dedicated exclusively to the official Sonarr Discord server.

Data Processing

SonarrBot inspects incoming message content ephemerally in-memory to match support keywords, regex patterns, and moderation triggers. Message content is not permanently stored or indexed.

Data Storage

The bot runs entirely on Team Sonarr’s self-hosted infrastructure. The only data temporarily retained is contextual message snippets attached to explicit moderation actions (e.g., warnings, mutes, bans) for audit logging by server moderators. No user data is sold, transferred, or shared with third parties.

Data Removal

Users may request the deletion of moderation records concerning them by contacting the Sonarr Discord moderation team.

SonarrBot Terms of Service

Use of SonarrBot is subject to the Sonarr Discord server rules as specified in the #rules channel.
